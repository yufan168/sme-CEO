# Agent Prompts

把 `src/agents.js` 的設計規格轉成可直接貼進 Claude 或 ChatGPT 使用的提示詞。

目前收錄客戶服務部的三個 Agent，對應網站上的 A01、A02、A03。

## 使用方式

1. 開一個新對話
2. 把對應的 `.md` 檔內容整段貼進去
3. 接著貼入該 Agent 的輸入資料（顧客訊息、分類結果或查詢結果）

三個 Agent 是**依序**使用的，前一個的輸出就是後一個的輸入：

```
顧客訊息
  → A01 問題分類員      輸出：分類結果
  → A02 客服資料查詢員   輸出：已確認資料／來源／缺口
  → A03 客服回覆草擬員   輸出：回覆草稿
  → 人：主管審核
  → 人：送出回覆
```

## 設計原則

每個 prompt 都明確寫出「不能做什麼」，且都要求在資訊不足時回報缺口，而不是自行補答案。

Agent 不具備直接對外送出的權限。草稿一律經人審核後由人送出。

| 檔案 | 對應 | 類型 |

| `a03-reply-drafter.md` | A03 客服回覆草擬員 | Worker 執行員 |
