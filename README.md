# 我的 AI OS ｜ 主管版 v8.1

© 2026 酒Ann。僅供課程學員本人使用（單一部署一位學員）；禁止開放他人共用、轉售或改作營利。

一套跑在自己 Vercel 帳號上的 AI 作業系統：把 AI 從聊天工具，變成公司裡真的會做事的數位員工團隊。
主管版在員工班平台之上，補齊「一家公司」該有的那一層：組織圖、六型 AI 員工與負責人、流程圖、治理三支柱、不綁平台的自動化，頂著一個 CEO 戰情室。資料存在你自己的 Neon 資料庫，金鑰加密後存在同一個資料庫，瀏覽器只看得到末四碼。

## 它能做什麼

**CEO 戰情室**
最上面一個大數字「等你出手」：把所有排隊等你判斷的事情加總，旁邊直接告訴你哪裡需要你。
戰情室回答的不是「所有事情現在怎樣」，而是「我現在該把注意力放哪」。
下面是團隊規模、公司大腦厚度、自動化今天觸發次數、今天核准送出幾則，
再下面是待真人審查清單、進度看板、執行時間軸甘特圖與本月 token 用量（可設警戒門檻，超標亮黃）。

**組織圖**
公司 → 部門 → AI 員工三層，一張圖看完你的 AI 公司現在長什麼樣。
金色是 AI 員工、後面標著它的類型，紅框代表這位還沒有人負責。
圖下面會直接點出結構破洞：哪個部門是空的、哪位 AI 沒人認領、整家公司有沒有人在審。

**治理三支柱**
柱一權限，owner／editor／viewer 三級各能做什麼。
柱二審核，你自己定「哪幾類 AI 草稿一定要停下來細讀」，命中的草稿會標出命中哪一條、為什麼。
柱三留痕，誰、什麼時候、核准或退回了什麼，只寫不改，出事才追得到源頭。
這一頁就是「權限表 ＋ 審核規則 ＝ 你的一頁管理制度」。

注意這條線不能調：規則決定的是「哪幾則要你停下來細讀」，不是「哪幾則可以不經過你」。
對外發送在這套系統裡永遠、無條件要人按下去。

**AI 員工與範本庫**
53 張 Agent 身分卡：八張通用（研究、知識、行銷、客服、行政、主筆、校稿、統籌）加上 13 個行業（餐飲、電商、零售、美業、診所、補教、房仲、旅宿、製造貿易、專業服務、法律、健身、寵物）的專屬員工，行業篩選器一選就只看相關的。每一張都含角色、使命、資料來源、工具、任務、產出、守則，一鍵套用成自己的設定；四格填齊之後可以領一張 **AI 員工卡**（可下載 PNG）。套用過的放在「我的 Agent」，隨時回來編輯。

**知識庫**
支援 rag-chunk-generator 的切片格式批次匯入，關鍵字／向量／混合三種檢索。Agent 回答時會引用來源檔名。

**流程圖**
每一條流程都可以展開成一張圖：綠色是 AI 做的、橘色粗框是一定要人的、藍色是迴圈，
虛線代表這一欄還會回頭讀更前面某一欄。沒有任何「人」節點的流程會被直接點名。
圖下面附 Mermaid 原始碼可以複製，貼進講義、簡報或 ChatGPT 都畫得出來。

**Workflow 任務交接檯**
35 條流程範本：從手動交接練習、自主團隊、品牌內容引擎，到 13 條行業一條龍（餐飲每日營運、電商出單到回購、法律諮詢到審閱…），再到迴圈與精煉示範（逐競品分析、逐商品寫描述、文案反覆打磨、內容月曆滿版展開）。Agent 依序上工，讀前一欄、寫自己那一欄，欄位 A 到 Z 最多 26 欄，全程留在資料庫。複製成「我的 Workflow」就能改成自己的版本。

**Agent 自主能力**
自主規劃（只給一句話目標，Agent 自己拆解出要開哪幾欄、找誰做）、工具迴圈（自己查知識庫、讀其他欄位、抓網頁）、Agent 之間互相提問。所有工具皆唯讀，執行軌跡完整呈現在介面上。

**品牌內容引擎**
從網站語料一路跑到可發布的文案，00 到 06 全在同一頁：品牌檔、我方語料、競品語料、跑分析、看結果、挑貼文、生成文案。

**提案區與文案庫**
Agent 產出的每一格矩陣、每一則貼文都先進提案區等你點頭。接受的提案自動入庫，生成的每一則文案都留底，可以回寫進知識庫讓知識員工與客服讀得到。

**客服中心**
LINE、WhatsApp、Telegram 三個管道，開一個或三個都行。AI 依知識庫產生回覆草稿，你審核、編輯，按送出才會真的發出去。**AI 永遠不會自動回覆顧客。**

**多品牌空間**
一個部署裝好幾個品牌。切換之後知識庫、AI 員工、Workflow、提案、文案、客服對話整套換掉，彼此看不到對方的資料。

**使用者與權限**
管理員／編輯者／唯讀三種角色，用 Email 與密碼登入。部署完會提示你把主帳號從「一組密碼」升級成一個真正的帳號；`APP_PASSWORD` 降級為緊急登入，確定不需要可以關掉。

**每一頁都有使用說明**
19 個功能頁，每一頁頂端都有摺疊式說明卡：這頁怎麼用、要先設定什麼、一個真實行業的使用場景。不用回頭翻手冊。

**英文介面**
側邊欄底下一顆「English interface」，整套介面連同 53 張 Agent 範本、35 條 Workflow 範本全部切成英文（787 條範本內容逐條人工翻譯）。你自己輸入的資料與 AI 產出保持原文，切回中文即還原。給有外籍同事或海外客戶的學員用。

**成果直通講義與簡報**
交接檯成果報告頁有「複製成講義指令」「複製成簡報指令」兩顆按鈕，把成果連同觸發語一起複製，貼進 Claude 就能接 joan-handout 或 slide-deck-generator 直接產出 A4 講義或投影片。

**版型配色**
六種配色可切換（石板藍、森林綠、梅紫、極簡黑、海洋藍、陶土棕），在「設定與備份 → 版型配色」。設定跟著品牌空間走，列印藍圖也會套用。

**雲端硬碟匯入**
貼上 Google 文件、試算表、簡報或 OneDrive 的分享連結，直接讀進知識庫。不必授權任何權限給系統。

## 金鑰全部在後台設定

**連線設定**頁有六個分頁：AI 模型金鑰、LINE、WhatsApp、Telegram、自動化與時區、向量檢索。填完按儲存立即生效，不必重新部署。

金鑰以 AES-256-GCM 加密後存進資料庫，加密金鑰由 `AUTH_SECRET` 派生。任何 API 都不會回傳金鑰原文。

### 還必須留在 Vercel 環境變數的只有四個

| 變數 | 用途 |
|---|---|
| `DATABASE_URL` | Neon 資料庫連線字串（接了 Neon 通常會自動帶入） |
| `AUTH_SECRET` | 登入簽章與金鑰加密的根，隨便一段夠長的隨機字串 |
| `APP_PASSWORD` | 初次登入與緊急登入用。建立管理員帳號後改用 Email 登入 |
| `EMBED_DIM` | 向量維度，選填，預設 1024 |

## 自動化串接

**不綁平台。** n8n、Make、Pabbly Connect 對外都只是「一個接收 POST 的 Webhook 網址」，接法完全一樣，
所以主管版改成一份可命名的清單，想接幾組接幾組，換平台不用改任何設定。

「自動化」頁是照著做就會通的五步引導：選平台 → 在該平台建 Webhook → 貼回來勾事件 →
按測試確認收得到 → （選做）產生進站權杖讓平台反過來觸發。每一步都寫了成功長怎樣、卡住怎麼辦。

出站事件：`run.step.done`、`run.done`、`run.error`、`proposal.accepted`、`proposal.rejected`、
`reply.sent`、`content.generated`、`schedule.opened`。每一則都落地 `automation_events`，
接不通的時候看事件紀錄就知道是這邊沒送出去、還是對方沒收到。

進站：`POST /api/hooks/<進站權杖>`，body 帶 `{"templateKey":"...","goal":"..."}` 就會開一張交接檯。
刻意只開單、不執行。機器可以把單開好，但 AI 真的動手與對外送出仍然要人按下去。
這就是「自動化不等於無人管理」。

## 技術結構

Next.js 15 ＋ Neon Postgres，部署在 Vercel。

交接檯採**單步執行**：一次 HTTP 請求只推進一步，前端反覆呼叫直到跑完。這樣不會撞上函式逾時，每一欄的成果也會立刻落地資料庫，關掉瀏覽器再打開還在。

資料庫遷移只使用 `CREATE TABLE IF NOT EXISTS`、`CREATE INDEX IF NOT EXISTS`、`ALTER TABLE ... ADD COLUMN IF NOT EXISTS`，**升級路徑完全沒有 DROP、TRUNCATE、DELETE**。舊資料一筆不會少。

## 檔案結構

```
package.json  next.config.mjs  tsconfig.json  middleware.ts  .env.example
app/      Next.js 路由與 API
lib/      資料庫、模型層、引擎、權限
public/   前端（app.html ＋ v3*.js；v3f 自動化引導、v3g 治理）
docs/     所有說明文件
scripts/  驗證器與煙霧測試
```

根目錄的 `學員部署指南.md` 與 `客服中心操作手冊.md` 只是指路檔，實際內容都在 `docs/`。它們存在的原因是讓舊版升級時直接覆蓋掉舊檔，可以安心刪除。
